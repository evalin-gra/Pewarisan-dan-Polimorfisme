# 🧩 Pewarisan dan Polimorfisme

### Exploring OOP with Java ☕

## ✨ About the Project

**Pewarisan dan Polimorfisme** adalah program sederhana berbasis Java yang dibuat untuk memenuhi tugas mata kuliah **Pemrograman Berorientasi Objek (PBO)**. Program ini menggunakan objek `BujurSangkar`, `Lingkaran`, dan `Silinder` untuk mempelajari penerapan konsep OOP dalam perhitungan geometri.

## 🚀 Features

- 🟩 Mengelola objek bujur sangkar, lingkaran, dan silinder.
- 📐 Menghitung luas bujur sangkar dan lingkaran.
- 🧮 Menghitung volume silinder.
- 🎨 Menampilkan informasi warna dan ukuran objek.
- 🔄 Menggunakan method `printInfo()` pada setiap objek.

## 🧠 Concepts Applied

- **Inheritance** — Menerapkan pewarisan atribut dan method antarkelas.
- **Polymorphism** — Memungkinkan method yang sama memiliki perilaku berbeda sesuai objek.
- **Encapsulation** — Mengakses data objek melalui getter.
- **Constructor** — Menginisialisasi objek dengan nilai tertentu.
- **Methods** — Menghitung luas, volume, dan menampilkan informasi objek.

## 🛠️ Tech Stack

- ☕ Java
- 🧩 Object-Oriented Programming (OOP)

## 🎯 Learning Goals

- Memahami konsep inheritance dan polymorphism.
- Mengenal hubungan antarkelas dalam Java.
- Menggunakan constructor dan getter.
- Menerapkan method untuk perhitungan geometri.
- Memahami penggunaan objek dalam program Java.

## 📝 Project Note

Proyek ini dibuat sebagai latihan penerapan konsep pewarisan dan polimorfisme dalam Java melalui contoh objek geometri sederhana.
